Permit portal file size limits: how to fit plan sets

Short answer: every city and county sets its own limit, often per file. Check the portal's upload instructions, then shrink only the images inside your PDF so linework and sheet text stay crisp. If the set is digitally sealed, shrink first and seal last.

Find your limit

Look for the jurisdiction's "electronic plan review" or "digital submittal" guide. It usually lists:

  • A maximum size per file, and sometimes per submittal
  • Whether each sheet must be its own PDF or the set must be one file
  • File naming rules, such as sheet number first
  • Whether PDFs must be unlocked, searchable, flattened or bookmarked

Rules differ even between portals that use the same software, so always check the guide for your jurisdiction.

Why plan sets get so big

  • Scanned or photographed sheets instead of PDFs printed from CAD or BIM
  • Raster images in the drawings, such as site photos, aerials and renderings, at full resolution
  • Exports at 600 dpi or more when 200 to 300 dpi reads well on screen
  • Layers and hidden content kept in the export

How to fit the set

  1. Re-export from CAD or BIM as a vector PDF where you can. That alone is often the biggest saving.
  2. Shrink the images, not the linework. In FoldSize on iPhone or iPad, type the portal's limit (or save it once as "County permit portal") and tap Fit. It shrinks the pictures inside the PDF and leaves the text, links and form fields alone.
  3. Split by discipline or sheet if the portal takes several files. FoldSize can split a PDF into parts that each fit.
  4. Make scans searchable if the portal asks for searchable PDFs. FoldSize Pro adds the text of scanned pages, found on your device.
  5. Name files the way the portal asks before you upload, so reviewers can find each sheet.

Sealed and signed drawings

Changing a digitally signed or sealed PDF breaks the signature, and the reviewer will see it as invalid. Shrink and combine the set first, then apply the seal or signature as the last step before upload.
